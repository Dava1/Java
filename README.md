# Java Projects Repository

This repository contains a collection of Java projects, experiments, and coding exercises created during learning, coursework, and hands-on practice. Each folder is a separate mini-project or assignment and showcases different Java concepts such as data structures, networking, parsing, simulations, and application logic.

## Repository overview

- `DBjdbc` – Java database connectivity examples using JDBC.
- `DoubleLinkedList` – custom implementation and usage of a doubly linked list.
- `HttpTrain` – HTTP-related Java experiments or client/server training exercises.
- `KrizovatkaUchurov` – project related to algorithmic or graph-like problem solving.
- `LexikalAnlyzing` – lexical analysis / parsing exercises.
- `MonteCarloMethod` – Monte Carlo simulation implementation.
- `PDFParse` – parsing and processing PDF content in Java.
- `Server` – server-side Java application or backend component.
- `TTCMarconi` – Java project focused on a specific assignment or domain task.
- `snake` – classic Snake game implementation.

## Goals

This repository is meant to:

- practice Java programming fundamentals and advanced concepts
- experiment with small real-world programming tasks
- build reusable solutions and problem-solving patterns
- store personal learning projects in one place

## Getting started

1. Install a Java Development Kit (JDK) version 8 or newer.
2. Clone this repository.
3. Open the project folder you want to run.
4. Compile the Java files:

```bash
javac *.java
```

5. Run the main class:

```bash
java Main
```

Note: Some folders may have their own specific instructions, dependencies, or entry points. Please check the individual project directory for details.
